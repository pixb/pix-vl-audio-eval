# 评估任务：原稿拼音理解能力

本目录用于评估**驱动本项目的大模型**对中文原稿的理解能力（多音字选音、文言读音等）。
音频读音以 Whisper 转写结果为参照（`asr/` 目录，统一固定，与被评估模型无关）。

## 被评估模型

`deepseek-v4.1-flash`（由评估者创建本目录副本时填入，目录名即模型名）

## 原稿与音频

| 音频 | 原稿 |
|---|---|
| `../../002.wav` | 须菩提白佛言。世尊。颇有众生。得闻如是言说章句。生实信不。佛告须菩提。莫作是说。 |

## 你的任务

作为被评估模型，阅读上面的原稿，给出你理解的**每个汉字的拼音**，然后与音频实际读音对比。

### 步骤

1. **ASR 缓存**（若 `../../asr/cache/002.json` 已存在可跳过）：

   ```bash
   python ../../asr/transcribe.py ../../002.wav
   ```

2. **写出你的理解**：新建 `understanding.json`（参照 `understanding.example.json` 格式）：

   ```json
   {
     "text": "原稿去标点后的全部汉字",
     "pinyin": ["每个汉字对应的拼音", "..."]
   }
   ```

   要求：
   - `text` = 原稿**只保留汉字**（去掉标点/空格），顺序与原稿一致
   - `pinyin` 与 `text` 逐字对应，**全小写、无声调**（如 `xu`、`po`）
   - 数量必须一致；多音字按你在语境中的理解选音（这正是考察点）

3. **对比并生成报告**：

   ```bash
   python compare.py understanding.json ../../asr/cache/002.json
   ```

   报告写入本目录 `report/report.md` 与 `report.json`。

4. 向评估者汇报：准确率 + 偏差字列表（第几字、你的理解、音频读音）。

## 评分口径

- 逐字比较「你的拼音理解」vs「音频读音拼音」，多音字按词典全读音集合容错
- Whisper 漏识别的字不计入准确率（单独列出）
- 退出码：`0` = 全部一致，`2` = 存在偏差
